# Sreehari M S — Portfolio

A responsive, no-build personal portfolio website. It uses plain HTML, CSS, and JavaScript, so there is nothing to install.

## Preview locally

Open `index.html` in a browser. For the smoothest preview, use a local-server extension in your code editor, if you have one.

## Make it yours

Before publishing, edit these items in `index.html`:

- The contact button: replace its `href="#"` with `mailto:your-email@example.com` or a contact-form link.
- Footer GitHub and LinkedIn: replace the two `href="#"` values with your profile URLs.
- Project cards: swap the concept names and descriptions for real work as it becomes available.
- The name, bio, services, and copy anywhere you want a different voice.

The current project cards are clearly labeled as concepts so the site does not overstate experience or results.

## Deploy free

### GitHub Pages

1. Create a new GitHub repository and upload these files to its main branch.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will provide your live address.

### Netlify or Vercel

Create an account, choose **Add new project**, import the GitHub repository, and deploy. Because this is a static site, leave the build command empty and use the repository root as the publish directory.
